# 番組フォーマット — 華流テック通信 / HAL Daily Briefing

> 参照: [requirements-v1.0.md](./requirements-v1.0.md) §3, §4, §14, [meeting.md](./meeting.md) ラウンド3
> 想定: Sprint 1B 以降の台本生成、Sprint 2 以降の音声化で使用するテンプレ。

## 1. 配信仕様

| 項目 | 値 |
|---|---|
| 配信頻度 | 平日 (月〜金) |
| 収集・生成バッチ | 23:00 JST |
| 朝確認 | 7:00〜7:50 JST |
| 公開 | 8:00 JST |
| 基本尺 | 5〜10分 |
| 最大尺 | 15分 |
| 1トピック目安 | 60〜120 秒 |
| トピック数 | 3〜5 本 |

## 2. エピソード構成 (Discover Daily 準拠)

```
[15s]  コールドオープン        — 今日の目玉トピック匂わせ
[10s]  オープニングジングル    — タイトルコール含む
[30s]  本日のラインナップ予告  — 3トピックを 1 行ずつ
        トピック1 [60-120s]      — Hook / Insight / Action
[3s]   トランジション SE       — トピック切替
        トピック2 [60-120s]
[3s]   トランジション SE
        トピック3 [60-120s]
[20s]  クロージング             — 明日への引き
[15s]  エンディングジングル
```

総尺レンジ ≒ 4分46秒 (3トピック60s) 〜 8分46秒 (3トピック120s)。トピック数5本まで延ばすと 12-14 分。

## 3. ジャンル配分テンプレ

要件 §4.3:

- **AI / Tech / OSS: 2 トピック**
- **Game / Subculture / Anime: 1 トピック**

例:
- T1: AI モデル / API / 価格戦争 / 研究成果
- T2: OSS / 開発者ツール / クラウド / スタートアップ
- T3: ゲーム / Bilibili / VTuber / サブカル / アニメ / ネット文化

## 4. アーク (情緒の流れ)

```
重要ニュース(序盤) → 深掘り(中盤) → 前向き話題(締め)
```

tc-newsflow の `arrangeDeveloperNewsArc` (hard → constructive → bright) を継承。中華圏向けでは:

- 序盤: 規制 / 価格戦争 / 重大リリース / 業界再編
- 中盤: 技術解説 / ユーザー体験 / 産業影響
- 締め: ゲーム新作・サブカル明るい話題 / 個人開発者・コミュニティの面白い動き

## 5. トピック内の構成 (各60-120秒)

```
[Hook]    つかみ — 何が起きたか
[Insight] なぜ重要か — 日本のリスナー視点での意味
[Action]  リスナーが取れる行動 — 注目ポイント、追うべきリポジトリ、見る価値のあるイベント
```

LLM プロンプトで強制 (FR-082)。各トピックは日本語 300 文字以内を目安 (tc-newsflow の `developerNewsTopicCharLimit` 思想)。

## 6. 音響演出

| 要素 | 仕様 |
|---|---|
| BGM | Lo-fi + 中華風アンビエント、全編に薄く敷く |
| オープニングジングル | タイトルコール込み、10秒 |
| エンディングジングル | 15秒 |
| トランジション SE | 短い (3秒)、トピック間に挿入 |
| ラウドネス | -16 LUFS 程度 (YouTube向け) |
| 出力形式 | mp3 192kbps / 48kHz (Irodori 出力流用) |

素材は商用利用 OK のフリー素材 or 自前生成 (Suno/Udio 等)。実在曲の無断使用は禁止。

## 8. Discord 台本投稿 (Sprint 1B)

- 番組タイトル
- 生成日時
- 採用トピック一覧 (見出しのみ)
- Markdown 台本本文
- 引用したソース URL 一覧
- 使用 LLM profile (A/B/C どれか)
- 推定尺
- 注意事項 (噂レベル、未確認情報、ネタバレ警告など)

## 9. YouTube 動画 (Sprint 3)

- 静止画 (番組ロゴ) + 波形ビジュアライザ (ffmpeg `showwaves`) + mp3 → mp4
- 説明欄に必須記載:
  > 本番組はAI音声キャスター HAL による自動生成番組です。
- 初期2週間は限定公開、その後一般公開を判断。
