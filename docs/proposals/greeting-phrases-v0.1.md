## 案A — 落ち着いた知性派 (現プレースホルダの正統進化)

| 用途 | フレーズ |
|---|---|
| タイトルコール (≦50字/10秒) | 「華流テック通信 — HAL Daily Briefing。今日も中華圏のテックを、ボクと一緒に見ていきましょう。」 |
| オープニング挨拶 | 「おはようございます、HALです。今朝も中華圏のテックニュースから、聞く価値のある話だけを選んでお届けします。」 |
| エンディング定型句 (≦100字/20秒) | 「今日の華流テック通信は以上です。〔明日への引き・可変〕。それでは皆さん、良い一日を。HALでした。」 |

コンセプト: ニュース番組としての信頼感を最優先した安定形。hal-persona §4 の暫定句との連続性が最も高く、移行違和感が最小。毎日聴いても疲れない「ラジオニュース」的体験。

## 案B — 親しみやすい隣人

| 用途 | フレーズ |
|---|---|
| タイトルコール | 「おはようございます。華流テック通信、HAL Daily Briefing の時間です。」 |
| オープニング挨拶 | 「キャスターのHALです。支度の手を止めずに、今朝の中華圏テック、要点だけ一緒に追いかけましょう。」 |
| エンディング定型句 | 「というわけで、今日はここまで。〔明日への引き・可変〕。明日の朝も、ボクと5分だけお付き合いください。」 |

コンセプト: 通勤・身支度中の「ながら聴き」への寄り添い。エンディングで毎回「明日もまた」の継続関係を言語化し、習慣化を促す。A 案より体温が高いが、テンションは persona 上限 (自然な感心レベル) 内。

## 案C — きびきびニュースアンカー

| 用途 | フレーズ |
|---|---|
| タイトルコール | 「華流テック通信、HAL Daily Briefing — 中華圏テックの今を、5分で。」 |
| オープニング挨拶 | 「HALです。本日のラインナップ、早速いきましょう。」 |
| エンディング定型句 | 「本日の華流テックは以上。〔明日への引き・可変〕。出典のリンクは概要欄に。HALでした。」 |

コンセプト: 情報密度最優先。挨拶の尺を削って本編 (topic) に配分し、「忙しい朝に最短で価値」を体験の核にする。エンディングで出典への導線を毎回固定で案内 (一次情報主義の番組性格を強調)。

## 選定基準チェックリスト (3 案とも作成時に自己点検済み)

- [x] 人格一致: 一人称「ボク」、落ち着いた低めトーンで読める、Vtuber 調・煽りなし (hal-persona §3)
- [x] TTS 読みやすさ: 難読漢字・英略語連続なし、句読点で自然なポーズが入る (Irodori 弱点考慮)
- [x] 尺制約: タイトルコール ≦50字、エンディング固定部 ≦100字 (show-format の秒数割当)
- [x] editorial-policy: 政治断定・ナショナリズム・「中国すごい」型ナラティブなし
- [ ] **毎日聴いて飽きないか — 人間が音読/試聴して判断** (選定の決め手)
