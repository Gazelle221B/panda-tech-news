# 編集方針 (Editorial Policy)

> 参照: [requirements-v1.0.md](./requirements-v1.0.md) §5, §6, [meeting.md](./meeting.md) ラウンド2
> 役割: 番組「華流テック通信 by HAL」のソース選定・採否判断・表現境界を定義する独立ドキュメント。台本生成プロンプト (Sprint 1B) と編集者 LLM (MiMo) の system 指示の参照元。

## 1. 基本姿勢

- 番組の主軸は **「中国語圏で何が起きていて、日本側から見ると何が面白いか」を冷静に翻訳・解説する** こと。
- 「中国すごい」「日本終わった」型のナラティブ、イデオロギー / ナショナリズム表明を採用しない。
- 情報の信頼性は NHK ニュース寄り、会話の空気は Rebuild.fm / TBS Podcast 寄り。
- 表現は硬すぎず、しかし根拠を曖昧にしない。

## 2. ソース優先順位

1. **中国語ネイティブの一次情報**: 企業/ラボ/大学/政府の公式発表、GitHub Release、論文プレプリント
2. **中国語ネイティブの準公式メディア**: 36Kr、机器之心、量子位、虎嗅、晚点LatePost
3. **中国語コミュニティ**: 掘金、SegmentFault、V2EX、bilibili 専門 UP 主、知乎
4. **噂/未認証**: Tier4、原則不採用

英語/日本語メディアに既に流れているネタは優先度を下げる。ただし、中国語圏ソースに **追加情報や現地文脈** がある場合は採用可。

## 3. Tier 定義 (要件 §6 再掲)

| Tier | 定義 | 単独採用 | 重み |
|---|---|---|---|
| 1 公式 | 企業/大学/政府/公式GitHub/arXiv 等の一次情報 | 可 | 最大 |
| 2 準公式 | 認証アカウント、高信頼メディア | 可 | 高 |
| 3 コミュニティ | 開発者コミュニティ、UP主、掘金、知乎 | 独立2ソースまたはTier1/2裏取り推奨 | 中 |
| 4 噂 | 匿名微博、未認証小红书、リーク | 原則不採用。例外時は独立2ソース必須かつ「噂」と明示 | 低 |

## 4. コミュニティ情報・噂の扱い

採用条件 (要件 §5.3):

- 独立 2 ソース以上で言及されている
- または、Tier1 / Tier2 ソースで追加確認できる
- または、高信頼アカウントの言及がある

採用時は **「噂レベル」「コミュニティで話題」「未確認」を口語で明示** する。

## 5. 政治・規制・国際関係

- イデオロギーやナショナリズムには踏み込まない
- ただし AI 規制 / ゲーム規制 / 輸出規制 / 半導体規制 / プラットフォーム規制など、ビジネス・技術への影響が不可分な場合は **事実として** 扱う
- その場合の主軸は政治評論ではなく **「技術・産業・ユーザー体験への影響」**

## 6. ネタバレ方針

- ゲーム / アニメ本編の重大ネタバレは避ける
- 新作発表 / 売上 / 運営方針 / 炎上 / イベント / 技術的特徴 / ファンコミュニティ動向は可

## 7. 英日既出フィルタ

要件 §5.1 + meeting ラウンド2 確定:

- **構造的フィルタ (a)**: そもそも英日に流れにくいソース (微信公众号、知乎長文、bilibili 动态、NGA、米游社、贴吧 等) を優先する設計で既出を回避
- **編集判定 (c)**: 明らかに ITmedia / TechCrunch JP / GIGAZINE 等に既出と分かるネタは LLM 編集判断で除外

LLM による Perplexity 検索ヒット数チェック (b) は **採用しない** (コスト過大、効果が見合わない)。

## 8. ファクトチェック強度

- **(a) 二次ソース確認**: 同一話題が独立 2 ソースで言及 → スコア加点
- **(b) 公式ソース重み付け**: ラボ / 大学 / 政府 / 企業公式を高スコア、噂系を低スコア
- **(c) LLM 二次検証は不採用** (コスト見合わない)

## 9. 採用領域の優先順位

1. 中国 AI
2. 中国 AI 関連 OSS
3. 中国テック
4. 中国ゲーム
5. 中国サブカル
6. 中国 OSS (非 AI)
7. 中国アニメ

通常回の配分目標は **AI/Tech/OSS:2 + Game/Subculture/Anime:1**。

## 10. 採用してはいけない表現

- 「中国すごい」「日本終わった」「中国製は粗悪」等の評価断定
- 国家や民族に対する一般化
- ヘイト / 差別 / プロパガンダ表現
- 中国メディア記事の本文転載 (要約と HAL 解説のみ)
- 実在人物の声真似 (Irodori-TTS 規約)
- 重大ネタバレ
- 検証不能なリーク情報の確定形 (「〜らしい」「〜と噂されている」が必須)

## 11. プロンプトへの落とし込み (Sprint 1B 向けメモ)

LLM 編集者 (MiMo) には本書 §1, §4, §5, §10 を **system 指示** に転写。LLM ライター (DeepSeek) には §7 (Hook/Insight/Action)、§9 (配分)、§10 (禁止表現) を渡す。

具体的な system プロンプト雛形は [prompts/](../prompts/) を参照。
